CODSOFT Data Analytics Internship

Task 3: Data Visualization Dashboard

Project Overview

This project focuses on creating data visualizations using Python to present sales data in a clear and understandable format. Different charts are used to compare product sales, understand sales distribution, and identify patterns in the dataset.

Objectives

- Create meaningful data visualizations.
- Compare sales across different products.
- Display sales distribution using a pie chart.
- Analyze the relationship between quantity sold and sales.
- Customize charts with titles, labels, and legends where appropriate.
- Present insights through easy-to-understand graphs.

Tools and Technologies

- Python
- Pandas
- Matplotlib
- Pydroid 3

Dataset

A sample sales dataset is included in the Python code. It contains the following columns:

- Product
- Month
- Sales
- Quantity

Visualizations Created

1. Bar Chart — Total Sales by Product
Compares total sales for Laptop, Phone, and Tablet.

2. Line Chart — Monthly Sales Trend
Shows how sales change across the months.

3. Pie Chart — Product Sales Distribution
Displays each product's share of total sales.

4. Scatter Plot — Quantity vs Sales
Explores the relationship between quantity sold and sales.

Project Files

- "task3.py" — Python source code
- "task3_sales_data.csv" — Dataset generated by the program

How to Run

1. Install Python.

2. Install the required libraries:
   
   "pip install pandas matplotlib"

3. Run the Python program:
   
   "python task3.py"

4. View the generated charts and review the output.

Key Learning Outcomes

- Understanding different chart types.
- Grouping and analyzing data using Pandas.
- Visualizing trends and comparisons.
- Communicating data insights through graphs.
